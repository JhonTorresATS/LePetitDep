# Historia de Usuario 1: Registro de usuario

Como visitante, deseo registrarme con mi correo electrónico
y contraseña para tener acceso a los servicios de LePetitDep.

## Criterios de Aceptación
- Es obligatorio que el formulario pida una contraseña y una dirección de correo electrónico. 
- El sistema tiene que comprobar que el correo electrónico tenga un formato válido (por ejemplo, usuario@dominio.com). 
- La contraseña debe contener al menos ocho caracteres. 
- El sistema debe presentar un mensaje de error explícito si ya existe un registro del correo.  
- Una vez que el usuario complete el registro con éxito, debe ser conducido a la pantalla de inicio de sesión o a su perfil directamente.
