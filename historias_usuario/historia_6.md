# Historia de Usuario 6: Historial de pedidos

Como usuario registrado, quiero consultar mis órdenes anteriores para recordar qué compré o para repetir un pedido.

## Criterios de Aceptación
- El historial solo debe ser accesible para usuarios autenticados.  
- Se debe mostrar una lista cronológica (del más reciente al más antiguo) de los pedidos realizados. 
- Cada pedido en la lista debe mostrar: número de orden, fecha, total pagado y estado (ej. Completado, Pendiente). 
- El usuario debe poder ver el detalle de los productos de cada pedido al hacer clic en él.
