# Funcionalidad 2: Comienzo de sesión  

Deseo iniciar sesión de manera segura con mi correo electrónico y contraseña 
para ingresar a mi cuenta y hacer pedidos como usuario registrado. 

## Criterios de Aceptación
- El sistema debe tener espacios para introducir la contraseña y el correo electrónico.  
- El sistema tiene que verificar que las credenciales correspondan a un usuario que ya esté registrado.  
- Un mensaje de error ("Credenciales inválidas") debe aparecer si las credenciales son incorrectas.  
- Cuando el usuario inicia sesión de manera exitosa, tiene que ser dirigido al menú o a la página principal.
