# LePetitDep

## Descripción
Se trata de una plataforma web hipotética concebida para gestionar la solicitud de café y artículos de panadería destinados a ser retirados en el establecimiento físico.
Cada una de sus funcionalidades se articula mediante un proceso secuencial y dirigido, con el propósito de asegurar una experiencia del usuario de alta calidad.

## Funcionalidades Principales
* Registro de usuario (crear cuenta con email y contraseña).
* Inicio de sesión (acceso seguro con validación).
* Consultar el menú, que incluye una enumeración detallada de los cafés, sus tarifas respectivas y sus correspondientes descripciones.
* Incorpore artículos al carrito mediante la selección precisa de las cantidades y los ítems correspondientes.
* Realizar pedido (confirmación, método de pago simulado y número de orden).
* Antecedentes de la solicitud (revisar órdenes previas).
